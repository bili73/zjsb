# Agent Note: 按页面和材料类型展示操作指引

Status: implemented
Scope: frontend/src/**, frontend/public/help/**, frontend/tests/**, SPEC.md, README.md
Last-verified: 2026-10-15

## Problem

功能增加后，单独阅读长说明书难以对应当前页面上的按钮，尤其是人员材料包、表格导出、异常复核和管理设置。说明书还缺少通用识别目录入口，并有通用导出命名与表格命名规则冲突。

## Decision

使用已安装的 Element Plus Tour 提供手动启动的短指引，每次按当前页面、材料类型和账号权限解释 3–6 个步骤。页面用稳定的 data-guide 锚点，重复批次使用独立 scope；只定位当前作用域中唯一可见的元素。缺失或尚未加载的目标明确提示，不借用其他批次的按钮。可选步骤按当前上传方式显示。

指引只滚动和讲解，不切换上传模式、不自动提交/保存/重跑/删除，不重建业务组件。遮罩禁止点击业务区域；叉号和 Esc 只退出指引，保留文件选择及修正草稿。页面切换、详情关闭、账号变化和卸载时清理指引及监听器。不开首次登录强制指引，不新增后端状态或依赖。

静态说明书按任务整理，包含指引入口、人员材料包、表格/通用识别选择、导出限制和管理员文件保留设置；更新日期为 2026-10-15，修正表格与普通业务导出的文件名区别。三个新增指引插图使用独立环境的虚构数据，不包含业务材料与真实账号。

OperationGuide 在打开期间用 requestAnimationFrame 跟踪内层滚动和布局变化；目标停止移动后再启用前后导航，关闭或卸载立即取消定位。ElTour 的 target-area-clickable=false 与焦点管理保护业务区域；捕获 Esc 阻止事件穿透到结果抽屉。前端锚点测试检查步骤与真实组件的契约，手册测试检查章节和插图链接。

## Alternatives considered

- 仅补长说明书：实现最小且便于完整检索；不能解决用户找不到实际按钮的问题，因此保留手册并添加短指引。
- 新装指引库或自写遮罩定位器：自定义能力强；现有 Element Plus 已提供目标高亮、焦点管理、步骤导航，复用它可减少维护面。
- 首次登录强制走完流程：覆盖新用户更直接；会阻断正在处理的工作，也无法涵盖不同权限和材料状态，因此采用手动开启、随时退出。

## Verification

207 项前端测试、vue-tsc 与独立 production build 通过。新增测试执行真实 OperationGuide 的 Vue 生命周期，覆盖缺失/隐藏/重复作用域、晚到目标、滚动位置更新、换步去除旧高亮、Esc 阻断、nextTick 期间关闭、权限/页面/任务变化与卸载清理，以及手册链接契约。

隔离 HTTP 服务使用 2 个虚构账号、5 个批次、6 个任务。浏览器验证上传文件保留、表格未保存标题保留、Esc 只退出指引、表格六步、人员包六步的作用域、体检六步、通用五步、管理及引擎十二步、只读三步、800×600 缩放和内嵌说明书目录。完成后无高亮残留；测试库没有修正、重跑、删除或新增上传记录，只有预置任务与预览读取。没有使用生产账号进行登录或调用真实识别模型。

记录位于 output/operation-guide-20261015/：frontend-tests.log、frontend-build.log、browser-checks.json 与截图。首次启动样例服务因空人员姓名被验证拒绝，未执行模型；改为未命名人员包后成功。早期连续导航检查遇到滚动/浮层未稳定的时序，保留记录，并通过等待目标及按钮启用状态完成复测。静态上线仅安装校验过的 assets/help，最后原子替换 index，保留旧静态文件备份和哈希资源；无需重启服务或模型。

## Consequences

复用现有组件减少依赖，用户在当前任务旁阅读短指引，草稿和上传选择不受影响。Element Plus 不自动跟踪所有内层滚动，因此打开指引时有逐帧定位成本，关闭后清理。说明与锚点存在跨组件契约，后续改按钮时须同步步骤和测试。当前构建仍有已有的大包体提示，未额外引入拆包重构。此次不验证 OCR 业务准确率或 Mac 发布。
